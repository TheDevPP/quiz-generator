# How content stays accurate

```
Doctor uploads verified handbook
        ↓
Claude API generates draft questions
        ↓
Doctor reviews every question
(approve / edit / reject)
        ↓
Only approved questions reach users
```

No question goes live without
a human health professional approving it.
